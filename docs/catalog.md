# Documentation catalog

Inventory of documentation prose under `docs/` on 2026-10-20 (top-level files,
`docs/adr/`, `docs/plan/`, `docs/report/`, `docs/reference/` and `docs/result/`). Category describes the primary
purpose; mixed
documents retain their own detailed scope and statuses.
**Accepted** records an explicit decision/plan acceptance, not successful implementation
or qualification. **Proposed** awaits acceptance. **Historical** is a dated snapshot;
**current** is maintained guidance or a ledger, not an architectural approval.
Locks and archived artifacts remain authoritative for their own protocols/results.

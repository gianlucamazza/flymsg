The MaleCNS annotation and weight tables are used under CC-BY 4.0 as stated by
Berg et al. 2026. A public GPL-3.0 repository publishes processing code for that
dataset; flymsg cites the paper and does not copy that code.

FAFB connectivity used with `--dataset fafb` comes from the Shiu et al. 2024
repository (MIT) and the public FlyWire annotation table (citations above).
flymsg does not redistribute those files.
